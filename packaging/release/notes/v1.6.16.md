# QR code with the camera

## Added

- Add from QR Code with Camera: shows the camera and adds the profile or subscription as soon as it reads a QR code. On Linux it needs Qt Multimedia, which the packages now install.

## Changed

- macOS: scanning a QR code on the screen no longer shows Proxor's own permission messages; macOS asks for Screen Recording itself.

## Fixed

- macOS and Linux: pressing Stop, or On-Demand stopping the proxy on another Wi-Fi network, while Proxor is still recovering from a sleep no longer starts the profile again.
