# Proxor on macOS

## Added

- macOS: a download for Apple Silicon Macs running macOS 15 or later, installed and updated with Homebrew: `brew install --cask ogstra/tap/proxor`.
- macOS: the menu-bar icon can be colored or monochrome, chosen with `Colored menu bar icon` in Settings, Appearance, Tray Icon. The monochrome icon follows the light or dark menu bar and still shows whether the proxy is running.
- macOS: the profile list and the log open native context menus.

## Changed

- macOS: TUN mode, the system proxy, autorun and in-app updates are not available yet. Update with `brew upgrade --cask proxor`.
- macOS: the interface uses the Fusion theme and follows the light or dark appearance of the system.

## Fixed

- macOS: Cmd+Q and Quit in the Dock menu close Proxor the same way as Exit and stop the core.
- macOS: Exit, Settings and About stay in Proxor's own menus.
- macOS: subscription requests identify the device as macOS and send the Mac model identifier, without the computer name or username.
