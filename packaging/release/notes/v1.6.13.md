# Safer updates and a freeze fix

## Added

- Ping works without administrator rights and falls back to TCP with a notice.
- Hotkey conflicts are reported, and settings pages explain the options a platform cannot do.
- QR codes can be added from an image file or the clipboard.

## Changed

- The tray menu is shorter: Show window, Restart Proxy and Exit.
- Updates are verified against the published checksums before anything is replaced.

## Fixed

- Downloading an update no longer fails with an error about renaming the downloaded file.
- Starting a profile or running a latency test while a subscription updates no longer freezes the app, and Stop cancels a start that is still pending.
- With Tun active, the automatic latency test waits for the tunnel instead of reporting every server as unavailable.
- The Windows archive and the winget manifest are built to spec.
