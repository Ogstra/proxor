# macOS, Linux and safer updates

## Added

- macOS: a download for Apple Silicon Macs on macOS 15 or later, installed and updated with Homebrew. TUN mode and the system proxy work through a small background service that asks for your administrator password once.
- macOS: Start with system, Dock reopen, an optional live speed next to the menu-bar icon, and no Dock icon while the window is closed to the menu bar.
- On-Demand by Wi-Fi network name works on macOS and Linux.
- Linux: autostart, screen QR scanning and global shortcuts through the desktop portals, and KDE Plasma 6 themes.
- macOS and Linux: Proxor reacts to sleep and wake. After waking it waits for the network, checks the core and retries the subscription updates that are due.
- The tray menu has a Connect and Disconnect switch.
- Tun: an option to send WireGuard, OpenVPN and Tailscale through the proxy instead of leaving them outside it.

## Changed

- Private networks you are not attached to, such as 10.10.10.0/24 behind the proxy, now go through the proxy. Only the networks of this machine stay local.
- The tray menu is shorter: Show window, Connect or Disconnect and Exit.
- A manual Stop on macOS pauses Tun and the system proxy at once, so DNS does not drop.
- Reopening Proxor on macOS brings back the connection it had when it quit.
- Updates are verified against the published checksums, downloads retry longer, and a failed update on Windows offers a manual download and keeps the installed version.

## Fixed

- Starting a profile or testing latency while a subscription updates no longer freezes the app, and Stop cancels a start that is still pending.
- Windows: downloading an update no longer fails with an error about renaming the downloaded file.
- Linux: the Tun script no longer aborts on a host without iptables or IPv6, and Arch is not offered a release without the Linux build.
