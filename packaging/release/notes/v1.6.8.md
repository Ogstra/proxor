# Updating knows who owns the install

## Added

- Linux: the AppImage updates itself in place, replacing the file it was started from.
- Every install records the channel that put it there in the startup log.

## Changed

- An install managed by a package manager no longer offers a self-update. The update dialog names the manager that owns it and shows the command to run, ready to copy.

## Fixed

- Linux: applying an update closed the app and nothing reopened it, because the Debian, Fedora and Arch packages do not ship the updater the app was about to launch. The app now stays open and explains what to do instead.
- Linux: the update check reported a failure on every channel instead of reporting that a new version exists.
- Updates are verified against the checksums published with the release before anything is replaced.
- Restarting from the app's own menu relaunched the wrong file when running as an AppImage.
