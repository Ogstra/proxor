# Linux packages, safer updates and verified builds

## Added

- Linux downloads: an AppImage, a Debian `.deb`, a Fedora `.rpm`, a Flatpak bundle and an Arch source recipe.
- Windows: a managed archive with winget manifests, for installs and upgrades through `winget`.
- Linux: the AppImage updates itself in place, replacing the file it was started from.
- Subscriptions are checked again after the machine resumes from sleep.
- `Add from QR Code on Screen` is back in the profile menu.
- Every install records the channel that put it there in the startup log.

## Changed

- An install managed by a package manager no longer offers a self-update. The update dialog names the manager that owns it and shows the command to run, ready to copy.
- Updates are verified against the checksums published with the release before anything is replaced.
- The libraries built into Proxor are taken from fixed release archives and checked against a known checksum before they are compiled, so every build ships exactly the sources that were reviewed.
- Linux: the light and dark mode can be chosen with any theme.
- An install under a read-only directory keeps its configuration in the user's application data directory.

## Fixed

- Linux: the tunnel no longer starts before the proxy is listening.
- SSH sessions survive turning the tunnel on.
- Traffic to private networks bypasses the tunnel, so devices on the local network stay reachable.
- FakeIP answers address queries only.
- Windows: the release archives no longer store backslash path separators, which tools that follow the ZIP specification could not read.
- Windows: the archives keep the `proxor` folder at their root whichever tool builds them.
- The automatic test on opening a subscription waits for the tunnel instead of reporting every server as unavailable.
- Linux: subscription requests carried no hardware id, computer name or username.
- The username switch for subscription requests had no effect of its own.
- Startup work held back by Tun authorization now waits instead of being cancelled, so a restart after an update refreshes subscriptions.
