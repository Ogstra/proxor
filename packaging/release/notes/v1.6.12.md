# macOS, Linux and sleep recovery

## Added

- macOS: a download for Apple Silicon Macs running macOS 15 or later, installed and updated with Homebrew: `brew install --cask ogstra/tap/proxor`. The update window shows `brew upgrade --cask proxor`.
- macOS: TUN mode and the system proxy work through a small background network service. macOS asks for your administrator password once to install it. Both pause while no profile runs and your previous network settings come back when you stop or quit.
- macOS: Start with system, a Dock click that reopens the window, and the native macOS prompts for Location and Local Network at the first start. Scanning a QR code from the screen explains the Screen Recording permission instead of failing silently.
- macOS: the menu-bar icon can be colored or monochrome. The monochrome icon is dimmer while disconnected. An optional live speed can be shown next to the icon, from Settings or the menu-bar menu.
- On-Demand by Wi-Fi network name now works on macOS and Linux, and Linux shows why when it cannot read the network name.
- Linux: autostart, screen QR scanning and global shortcuts go through the desktop portals on Wayland and in Flatpak, KDE Plasma 6 themes are supported, and Tun captures IPv6 by default.
- Ping works without administrator rights and falls back to TCP with a notice. Hotkey conflicts are reported. Settings pages disable and explain the options a platform cannot do. QR codes can be imported from an image file or the clipboard.
- macOS and Linux: Proxor reacts to the computer going to sleep and waking up. After waking it waits for the network, checks the core, re-applies Tun and the system proxy on macOS, and retries the subscription updates that are due.

## Changed

- The tray menu is the same on every platform: Show window, Restart Proxy and Exit, plus the speed switch on macOS.
- macOS: reopening Proxor after quitting brings back the connection it had when it quit.
- Linux: the systemd-resolved notice appears only when it applies.
- The libraries built into Proxor come from fixed release archives checked against a known checksum before they are compiled, so every build ships exactly the sources that were reviewed.
- The release pipeline no longer depends on tooling that GitHub is retiring, so future updates keep arriving on every channel.

## Fixed

- Windows: downloading an update no longer fails with an error about renaming the downloaded file.
- Starting a profile or running a latency test while a subscription updates no longer freezes the app, and Stop cancels a start that is still pending.
- macOS: Proxor.app has its own icon in the Dock, Finder and Launchpad.
- macOS: Cmd+Q and Quit in the Dock menu close Proxor the same way as Exit and stop the core.
- macOS: subscription requests identify the device as macOS and send the Mac model identifier, without the computer name or username.
