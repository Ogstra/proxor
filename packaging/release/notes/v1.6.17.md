# Interface and usability fixes

## Added

- QR codes with the camera on Windows and Linux.
- The theme follows the system light and dark mode on Windows and Linux.

## Changed

- Shortcuts: QR code and link is Ctrl+Shift+Q, Move is Ctrl+Shift+M, Copy Proxor links is Ctrl+Shift+C. Ctrl+Q quits. Find is in the Profiles menu.
- The Tun settings tab and the macOS service use one name each.
- Fewer confirmation and notice dialogs.
- Clearer error messages and input checks in the profile editors.
- Colors, icons and fonts follow the theme and the screen scale. Stop has its own shape.
- Linux tray icons come in more sizes.
- macOS: the Proxor service is offered at the first start and stays across Homebrew upgrades.

## Fixed

- The update dialog keeps its error and has a Cancel button, and a manual update check says why it cannot run.
- After a sleep, the profile restarts as it was started, including On-Demand.
- The Flatpak is no longer published.
