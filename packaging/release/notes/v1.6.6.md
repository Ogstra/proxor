# Windows archive layout

## Fixed

- Windows: the release archives stored their paths with backslash separators, so extracting them produced files named `config\geoip.dat` instead of a `config` folder. Tools that follow the ZIP specification, including the Windows Package Manager, could not read them.
- Windows: the archives now always keep the `proxor` folder at their root, whichever packaging tool builds them, so the path inside the archive no longer depends on the build host.
