# Linux packages, Tun routing and Windows archives

## Added

- Linux downloads: an AppImage, a Debian `.deb`, a Fedora `.rpm`, a Flatpak bundle and an Arch source recipe, each built from the published source archive.
- Windows: a managed archive with winget manifests, so Proxor can be installed and updated with `winget`.
- Subscriptions are checked again after the machine resumes from sleep.

## Changed

- An install under a read-only directory now keeps its configuration in the user's application data directory instead of failing to write beside the executable.

## Fixed

- Linux: the tunnel no longer starts before the proxy is listening, which used to leave the first connections after startup without a route.
- SSH sessions survive turning the tunnel on, because their routes are preserved instead of being captured.
- Traffic to private networks bypasses the tunnel, so printers, NAS boxes and other devices on the local network stay reachable.
- FakeIP answers address queries only, so the remaining DNS record types resolve normally.
- Windows: the release archives stored their paths with backslash separators, so extracting them produced files named `config\geoip.dat` instead of a `config` folder. Tools that follow the ZIP specification, including the Windows Package Manager, could not read them.
- Windows: the archives now always keep the `proxor` folder at their root, whichever packaging tool builds them, so the path inside the archive no longer depends on the build host.
